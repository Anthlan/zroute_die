# Aktuelles

Dieser Ordner enthält bewusst veröffentlichte Meldungen für die Startseite der DIE Drachenhalle.
Jede Meldung ist eine eigene Markdown-Datei und beginnt mit einem Metadatenblock.

## Dateiname

```text
YYYY_MM_DD_Kurztitel.md
```

## Vorlage

```markdown
---
title: "Titel der Neuigkeit"
date: "2026-09-24"
category: "Allgemein"
summary: "Kurze Zusammenfassung für die Startseite."
featured: false
---

Hier steht der vollständige Text der Neuigkeit.
```

`featured: true` hebt eine Meldung auf der Startseite besonders hervor. Die neueste hervorgehobene Meldung
wird zuerst angezeigt. Die Schreibweise der Allianz lautet auf der Website immer **DIE**.
