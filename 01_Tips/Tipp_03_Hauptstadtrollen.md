# 💡 Tipp #3 – Hauptstadtrollen

## Wofür ist dieser Tipp?

Dieser Tipp zeigt, welche temporären Boni die Hauptstadtrollen bieten, wer Vizepräsident werden kann und wann ein Amtsbonus tatsächlich auf eine Aktion angewendet wird.

## Tipp

Die Hauptstadt bietet starke temporäre Boni:

| Hauptstadtrolle | Boni |
| --- | --- |
| 🏗️ **Bauminister** | +50 % Bau · +25 % Forschung |
| 🔬 **Forschungsdirektor** | +50 % Forschung · +25 % Bau |
| ⚔️ **Verteidigungsminister** | +20 % Training · +20 % Ausbildungslimit |
| 🏥 **Taktischer Minister** | +20 % Heilung · +20 % Krankenhauskapazität |
| 🌾 **Zivilminister** | +100 % Nahrung, Metall und Öl |

### Vizepräsident

👑 Der Titel **Vizepräsident** ist nur für Mitglieder der Top-3-Allianzen verfügbar.

### Wann gilt der Bonus?

- ❌ **Kein Bonus:** Aktion gestartet → Titel erhalten → laufende Aktion erhält keinen nachträglichen Bonus.
- ✅ **Bonus aktiv:** Titel erhalten → Aktion gestartet → Amtsbonus wird angewendet.

> **Wichtig:** Der Bonus gilt nur während der Amtszeit und nur für Aktionen, die **nach Erhalt des Titels gestartet** werden.
