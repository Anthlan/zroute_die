# `05_Chatbilder/Chibi`

Dieser Unterordner enthält bewusst überzeichnete Chibi-Reaktionsbilder für den Allianzchat. Für sie gelten die besonderen Chibi-Vorgaben aus `06_Design-Guidelines`.

Die Nummer `05` verweist auf den übergeordneten Bereich `05_Chatbilder`.

## Benennungsregeln

- Schema: `YYYY_MM_DD_HHMM_Kurztitel_[Hauptfiguren].Dateiendung`.
- Beispiel: `2026_09_23_0751_AngriffsknopfChibi_Somea_Anthlan.png`.
- Der Zeitstempel steht zuerst. Kurztitel und Hauptfiguren enthalten keine Leerzeichen; mehrere eindeutig erkennbare Hauptfiguren werden jeweils mit einem Unterstrich angehängt.
- Spielernamen übernehmen ihre bestätigte Groß- und Kleinschreibung. Dateiendungen werden kleingeschrieben.
- `README.md` ist von diesem Bildschema ausgenommen.
