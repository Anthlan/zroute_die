# Nützliches

Auf der Website bündelt **Nützliches** zwei zentrale Informationssammlungen:

- [Tipps](Tipps/README.md) – die zentrale Sammlung für Spielwissen; nach **Art** und **Thema** filterbar
- [Allianz](Allianz/README.md) – Regeln, Rollen und wiederverwendbare Mitteilungen

Die Quellordner `Anleitungen`, `Strategien` und `Analysen` bleiben für bestehende Ablagehinweise und eine mögliche spätere Nutzung erhalten, erscheinen vorerst aber nicht als eigenständige Rubriken auf der Website. Anleitung, Strategie und Optimierung werden stattdessen als Art-Tags direkt an den Tipp-Dateien gepflegt.

Neue öffentliche Spielinhalte werden als nummerierte Tipp-Dateien unter [`Tipps`](Tipps/README.md) abgelegt. Die Website liest ihre Inhalte und Metadaten beim Build automatisch ein.
