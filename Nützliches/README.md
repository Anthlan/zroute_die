# Nützliches

Dieser Bereich bündelt die fünf Informationssammlungen, die auf der Website unter **Nützliches** erscheinen.

- [Tipps](Tipps/README.md) – kurze, direkt anwendbare Hinweise mit Text und Grafik
- [Anleitungen](Anleitungen/README.md) – ausführliche Schritt-für-Schritt-Erklärungen
- [Strategien](Strategien/README.md) – taktische Planungen und Kampfkonzepte
- [Analysen](Analysen/README.md) – Auswertungen und nachvollziehbare Erkenntnisse
- [Allianz](Allianz/README.md) – Regeln, Rollen und wiederverwendbare Mitteilungen

Neue Inhalte werden im passenden Unterordner abgelegt. Die Website liest diese Dateien beim Build automatisch ein.
