# Strategien

Dieser Ordner enthält taktische Erkenntnisse, Kampfkonzepte und längerfristige Planungen für die Allianz.

Die Inhalte sollen handlungsorientiert, nachvollziehbar und für spätere Einsätze wiederverwendbar sein.

## Benennungsregeln

- Vorläufiges Schema: `Thema_Kurztitel.Dateiendung`, beispielsweise `Waechterkampf_Angriffsplan.md`.
- Thema und Kurztitel beschreiben die Strategie ohne laufende Nummer. Wörter enthalten keine Leerzeichen; Umlaute werden als `Ae`, `Oe`, `Ue` und `ss` geschrieben.
- Zusammengehörige Dokumente und Grafiken erhalten exakt denselben Basisnamen.
- Sobald erste Strategien vorliegen, kann dieses Schema anhand der tatsächlichen Inhalte weiter präzisiert werden.
- Dateiendungen werden kleingeschrieben. `README.md` ist von diesem Inhaltsschema ausgenommen.
