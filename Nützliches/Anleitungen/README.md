# Anleitungen

Dieser Ordner enthält ausführlichere Schritt-für-Schritt-Anleitungen zu Spielmechaniken, Abläufen und wiederkehrenden Aufgaben.

Zusammengehörige Text- und Bilddateien werden direkt hier abgelegt und über denselben Basisnamen miteinander verbunden.

## Benennungsregeln

- Vorläufiges Schema: `Thema_Kurztitel.Dateiendung`, zum Beispiel `AllianzShop_SchrittFuerSchritt.md` und `AllianzShop_SchrittFuerSchritt.png`.
- Thema und Kurztitel beschreiben die Anleitung ohne laufende Nummer. Wörter enthalten keine Leerzeichen; Umlaute werden als `Ae`, `Oe`, `Ue` und `ss` geschrieben.
- Zusammengehörige Texte, HTML-Dateien und Grafiken müssen exakt denselben Basisnamen haben.
- Sobald erste Anleitungen vorliegen, kann dieses Schema anhand der tatsächlichen Inhalte weiter präzisiert werden.
- Dateiendungen werden kleingeschrieben. `README.md` ist von diesem Inhaltsschema ausgenommen.
