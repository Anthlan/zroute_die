# Analysen

Dieser Ordner enthält Auswertungen zu Events, Kämpfen, Accounts und Serverentwicklungen.

Analysen dokumentieren Beobachtungen, Datengrundlage und Schlussfolgerungen so, dass daraus Strategien oder Entscheidungen abgeleitet werden können.

## Benennungsregeln

- Schema: `YYYY_MM_DD_Kurztitel.Dateiendung`, beispielsweise `2026_09_23_Serverentwicklung.md`.
- Das Datum bezeichnet den Stand beziehungsweise Abschluss der Analyse. Der Kurztitel steht ohne Leerzeichen in lesbarer Binnen-Großschreibung; Umlaute werden als `Ae`, `Oe`, `Ue` und `ss` geschrieben.
- Zusammengehörige Auswertungstabellen, Texte und Grafiken erhalten exakt denselben Basisnamen.
- Dateiendungen werden kleingeschrieben. `README.md` ist von diesem Inhaltsschema ausgenommen.
